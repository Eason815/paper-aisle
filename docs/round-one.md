# 第一轮：调研阅读入口

完成日期：2026-10-23。

## 本轮交付

- 合并首批10篇Agent摘要数据；旧12篇公开数据逐对象保持不变，datasetId仍为paper-aisle-main-v1。
- 默认显示“本轮调研”，可切换“基础阅读”与“全库”；集合和问题目录由JSON配置。
- 新增可折叠的研究问题筛选；核心方向维持原有配置。
- 新论文提供中文一句话导读；OctoTools、记忆管理分析、AgentAbstain提供三类可点击概念图。图示均标注摘要依据和概念示意身份。
- 详情在没有扩展方法/发现时显示现有速读；作者与来源可展开。
- 按本次打开的论文序列连续翻篇，切换前保存便签；关闭恢复焦点；正文支持J/K，输入框不触发。
- 便签增加三行模板；对比增加任务/场景。
- 阅读记录支持全状态JSON导出、恢复前预览、不同便签合并、标签并集和状态优先级选择；跨datasetId恢复被拒绝。
- 当前集合Markdown导出包含稳定论文ID、原文链接及个人记录；完整备份保留暂不在目录里的论文状态。
- 增量数据转换脚本提供预览和写入，重复执行保持22篇且不会重复收录。

## 验证

- npm run check：生产构建、测试类型检查和26项测试通过。
- Draft202012Validator + FormatChecker：网站完整JSON Schema验证通过，22篇。
- 集成测试核对原12篇完整对象不变、无运行时解析警告、默认集合10篇、3篇图解以及连续翻篇与备份恢复。
- 浏览器检查覆盖1440px桌面与390px手机，三类图解、问题筛选、翻篇/刷新后便签、实际备份文件导出及恢复预览、Esc关闭与焦点恢复；控制台无错误。
- 原48篇首批渲染测试继续通过。

## 当前内容范围

首批仍是摘要级导读；本轮没有扩充为全文核读、没有生成具体实验提升数值，也没有把AI处理标为人工已读。轨道未知不会阻止浏览。真实原图、全文实验卡和大规模断点采集属于后续阶段。

个人状态依旧存于浏览器本地。建议开始积累便签后，定期从页头“阅读记录”导出完整JSON备份；备份不要提交到公开仓库。
