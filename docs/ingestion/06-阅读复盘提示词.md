# 从阅读记录到下一批选材

用户投入理解论文，Codex处理资料、元数据、格式和大部分来源检查。每篇便签可写三行：我的理解／与其他工作的区别／仍不明白什么。不要求所有论文都填。

```text
本次做阅读复盘，不新增论文、不发布网站。
读取docs/ingestion/现行规则、真实研究进度及我实际提供的Paper Aisle阅读笔记。
只根据笔记中明确表达的内容整理，不把收藏、已读或某类论文较多推断成兴趣或认可。
没有笔记时如实说明；只交付现有覆盖与可补看的路线，不虚构我的理解和疑问。

输出一页复盘：
1. 我明确表达过的理解，附对应论文ID/题名；
2. 我明确提出的问题，保留原意，区分未懂术语、方法差异与证据疑问；
3. 同问题下可比较的路线，以及当前材料还不能比较的条件；
4. 下一批最多10篇的选材目标，不必现在搜齐；
5. 值得另开全文核读的2～3篇及具体要核查什么。

不要把“已读”改成humanConfirmed/humanChecked，不改最终role、纳入决定或个人状态。
原始笔记、完整备份及含个人内容的复盘只保存到被Git忽略的.research-private/，
不写入public、共享research批次、提交说明或公开检查报告。
公开进度只保留必要的覆盖与任务状态，不复制私人便签。
以后制作下一批时，使用我明确认可的选材方向；未指定偏好仍继续Stage 01广泛扫描。
```
